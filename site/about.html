Why it exists

Built for networks that fight back.

Deep packet inspection, fingerprinting, UDP throttling, blocked endpoints. OryvexCore scans, verifies real HTTPS traffic before it says Connected, and serves the tunnel as a SOCKS5 proxy or a whole-device VPN.

Auto route

Tries WireGuard, then MASQUE, MASQUE² and Gool, and keeps the first one that passes real traffic.

Tor, built in

Arti (Rust Tor) inside the core on Windows and Android. Bridges fetched for you when Tor is blocked.

Pick your exit

Auto, Fastest (measured on connect) or a country. The exit list is fetched through Tor itself, never over your filtered line.

Hard to fingerprint

Chrome-shaped TLS, ClientHello fragmentation and obfuscation profiles from light to GFW.

Real scanning

Five scan modes from turbo to ironclad. Ironclad opens a full tunnel and sends a real request before trusting a gateway.

Proxy or VPN

A SOCKS5 proxy on 127.0.0.1:1819, automatic Windows system proxy for Bypass, or whole-device routing through Android VPN.

Ways through

MASQUE

Traffic hides inside an encrypted connection that looks like ordinary web traffic, over HTTP/3 or HTTP/2.

WireGuard

Lean and very fast. Best on networks that block known addresses but don’t look closely at traffic shape.

MASQUE²

MASQUE carried inside MASQUE, for a different exit address.

Gool

Tunnel in a tunnel: WireGuard inside MASQUE, or inside WireGuard. Slower, but it can be the difference.

Bypass, no tunnel

A direct route that reshapes the first packets of every connection and resolves names itself, so filters that read the site name are fooled. Your address stays the same. Beats packet-by-packet filters and DNS blocking, not filters that block by address. Windows and Android, --bypass.

Windows

Windows 10/11, x64: Desktop app. Windows 7/8/10/11, x86 and x64: OryvexVPN Lite.

Bypass automatically enables the per-user Windows system proxy and restores the previous setting when disconnected. It routes apps that honor Windows proxy settings; apps that ignore them still need an explicit proxy.

Android 5.0+

The Android app supports Bypass on its shipped ABIs: arm64-v8a, armeabi-v7a and x86_64. Enable Whole-device VPN to route device traffic; Android asks for its standard VPN permission.

Linux and macOS: the CLI can run Bypass when both oryvexcore and a native oryvex-bypass engine are built/installed. Use the local proxy from clients; there is no bundled GUI or whole-system Bypass VPN.
