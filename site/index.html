GET STARTED

Three steps.
One connection.

01

Install

Choose the Windows setup or an Android APK from the latest release.

02

Choose

Pick Auto, Tor, Fox or another connection from the Route section.

03

Connect

For Fox, first open Settings → Fox accounts and locations to sign in and select a server.

Android can route the whole device through its VPN service. On Windows, Fox uses a local SOCKS5 proxy, so applications must be configured to use it.
