# OryvexVPN visual preview

This static HTML, CSS and JavaScript preview is an illustration based on the Flutter app source. It is not the app and does not create a VPN or proxy connection, sign in, install a certificate, deploy a relay, access an account, measure traffic or retrieve locations. Status, activity and locations are examples. No credentials are collected. It shows Windows and Android settings together for the walkthrough; the real app varies by platform, route and state.

Run `python3 -m http.server --directory site 8000` from the project root, then visit `http://localhost:8000/preview/`. The silent walkthrough recording is `site/video/oryvexvpn-preview.mp4`.
