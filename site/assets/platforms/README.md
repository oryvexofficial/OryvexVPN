# Platform marks

The Windows and Android SVG marks are local copies of the Simple Icons brand glyphs, pinned
to the Simple Icons 16.x artwork. Source library: <https://github.com/simple-icons/simple-icons>.
The SVG artwork is CC0 1.0; the Windows and Android names and marks remain trademarks of their
respective owners. These marks are used only to identify the operating systems supported by the
OryvexVPN Bypass feature.
