Guide

Start in three minutes.

Install, choose a route, connect. Fox and the relay have their own steps below.

InstallFoxCloudflare relayLocationsTroubleshooting

Install

  1. Open Downloads and take the Windows x64 setup or the Android universal APK.
  2. On Android, allow installs from your chosen source when asked. On Windows, run the installer.
  3. Open OryvexVPN, pick a route and press Connect. Android asks for VPN permission once.

Connect with Fox

  1. Choose Fox in the Route card.
  2. Select Sign in with Mozilla and finish the account steps in the app.
  3. Pick a location and connect.

Fox is an unofficial client and needs an eligible Firefox Account. On Android it can route the whole device. On Windows it runs a local SOCKS5 proxy, so applications must be pointed at it.

Deploy your Fox relay

  1. Choose Fox, then Settings, Fox connection, Deploy Cloudflare relay.
  2. Press Token Template. Cloudflare opens in your browser (a system browser tab). Sign in, create the token and paste it into the dialog.
  3. Pick your Cloudflare account and press Deploy and configure Fox.

The app uploads the bundled Worker, creates a random secret, enables the workers.dev address and saves it to Fox. If saving to Fox fails it retries, and you can run a health check afterwards. The API token is not stored by OryvexVPN. OryvexVPN never sees your Cloudflare password.

Know what passes through. The relay owner can read relayed Fox requests, so use your own account. The relay does not carry VPN traffic, and the Mozilla sign-in web page does not use it. On some networks workers.dev may itself be blocked.

Relay notes on GitHub

Locations

Tor and Fox offer country selection. What is available depends on the route, service, network and account. Flags on this site are illustrations.

If it gets stuck

Check the selected route and account, then try another route or network. The Activity page in the app shows connection errors. For Fox, run the relay health check after deploying.
