How to use

Three taps to connected.

Install, pick a route, connect. The defaults are good; change them only when your network pushes back.

  1. Install
    Android 7.0+: choose the universal, ARM64 or ARMv7 APK. Windows 10 / 11: run the x64 setup installer.
  2. Pick a route
    Leave it on Auto, choose Tor, or select Fox to use a Firefox Account.
  3. Choose a Tor exit Tor route only
    Auto, Fastest, or a Country. Open Browse all countries to search the available exit list.
  4. Connect
    The app shows each stage live and reports Connected when the core says the selected route and proxy are ready. See the app

Connect with Fox

  1. Choose Fox under Route.
  2. Open Settings > Fox accounts and locations. The local dashboard opens in your browser.
  3. Add your Firefox Account and choose an available server location. Country flags appear in the server list.
  4. Return to OryvexVPN and press Connect. On Android, enable Whole-device VPN to route device traffic.

On Windows, configure an app to use the local SOCKS5 proxy shown in OryvexVPN. Fox is unofficial and is not made or endorsed by Mozilla; account access and service availability are set by Mozilla.

Point any app at it

The core serves a SOCKS5 proxy. Use socks5h so DNS goes through the selected route too. In Windows Bypass mode, the app also enables the Windows system HTTP proxy automatically. On Android, enable Whole-device VPN for device-wide routing.

socks5h://127.0.0.1:1819

For WARP tunnel routes, seeing warp=on means traffic is passing through WARP. Fox uses Mozilla’s service instead, and Bypass is direct and does not change your exit address.

curl -x socks5h://127.0.0.1:1819 https://www.cloudflare.com/cdn-cgi/trace

When it won’t connect

Turn it up one step at a time.

Nothing connects
Switch MASQUE to HTTP/2. If that handshake is blocked too, add ClientHello fragmentation. Then try WireGuard or classic Gool.
Connects, then drops
Take the obfuscation profile one step heavier: gfw for MASQUE, aggressive for WireGuard.
Scan is slow
Use the turbo scan, and say yes to reconnecting to your last working gateway.
Tor is blocked
Bridges are fetched for you. Or run Tor through the tunnel.
