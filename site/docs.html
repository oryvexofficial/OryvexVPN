Command line.

Every prompt has a flag, every flag has an environment variable. Mix them however you like.

Run it

With no arguments, OryvexCore asks its questions one by one. Flags skip them.

oryvexcore                                 # answer the questions as they come
oryvexcore --masque --turbo -4             # straight to work
oryvexcore --tor-only --tor-exit fastest   # plain Tor, fastest exit country
oryvexcore --tor-only --tor-exit de,nl     # Germany, else Netherlands
oryvexcore --wg --tor --tor-exit se        # Tor inside WireGuard, exit in Sweden
oryvexcore help                            # every flag and variable

Transports

--masque
MASQUE: the default. Looks like ordinary web traffic. Start here.
--wg
WireGuard: least overhead, fastest when it works.
--gool
Gool over MASQUE: WireGuard inside MASQUE, for a different exit address.
--gool-classic
Classic Gool: WireGuard inside WireGuard, two layers. Use when plain WireGuard is unstable.

Scanning

No address is hard-coded. OryvexCore measures real responses and picks the best gateway.

ModeUse it when
turbo
You want to connect fast; first answer wins
balanced
Default, good for most networks
thorough
You want the best ping, can wait
stealth
You want less noise on the network
ironclad
Gateways looked fine but never passed traffic

Obfuscation

MASQUE, Gool
firewall (default), gfw (heavier), off
WireGuard, classic Gool
balanced (default), aggressive, light, off

Start on the default. Didn’t connect or kept dropping? Go one step heavier.

HTTP/2 vs HTTP/3

MASQUE uses HTTP/3 (QUIC over UDP) by default. If your network throttles UDP, switch to HTTP/2 over TCP. If the HTTP/2 handshake gets blocked, fragment the ClientHello.

oryvexcore --h2
oryvexcore --h2 --fragment --fragment-size 8-24 --fragment-delay 5-15

Tor

Three modes, exit choice and bridges are covered on the Tor page.

oryvexcore --tor-only                   # Tor alone
oryvexcore --masque --tor               # Tor through the tunnel, Tor on :1820
oryvexcore --masque --tor-reverse       # the tunnel through Tor

FlagWhat it does

-4 / -6 / --dual
Scan IPv4, IPv6 or both
--peer <ip:port>
Force a gateway and skip scanning
--scan <mode>
turbo, balanced, thorough, stealth, ironclad
--noize <profile>
Obfuscation profile
--h2
MASQUE over HTTP/2
--fragment
Fragment the TLS ClientHello
--quick-reconnect
Always reuse the last working gateway
--tor-exit auto|fastest|cc
Where Tor leaves from
--tor-exit-strict
Fail instead of leaving elsewhere
--tor-bridge-file
Your own bridge lines
--bypass
Direct route with reshaped first packets, no tunnel (Windows, Android)

Docker

The SOCKS5 proxy has no authentication. Publish it on 127.0.0.1 only, or anyone on your network can use your tunnel.

docker run -it -p 127.0.0.1:1819:1819 -v oryvexcore-data:/data \
  -e ORYVEXCORE_PROTOCOL=masque \
  ghcr.io/owner/oryvexcore:latest

Troubleshooting

No connection at all
MASQUE on h2, then --fragment, then WireGuard or classic Gool.
Connects but nothing loads
The data check rejects that gateway and keeps scanning on its own.
Keeps dropping
Heavier obfuscation profile.
Slow
Drop from Gool to a single tunnel; try h3 if UDP is open.
